## How to run the programs

You need a C++ compiler.

| Your computer | What to install |
|---|---|
| Windows | [MinGW](https://www.mingw-w64.org/) or use [onlinegdb.com](https://www.onlinegdb.com) |
| Linux | `sudo apt install g++` |
| Mac | `xcode-select --install` |
| Nothing installed | Use [onlinegdb.com](https://www.onlinegdb.com) in your browser |

Then copy any program into a file and run it:

```bash
g++ program.cpp -o program
./program
```

On Windows, use `program.exe` instead of `./program`.

## How to study

1. Read **what it is** first.
2. **Type the program yourself** — do not just read it. Typing helps you remember.
3. Run it and check that you get the same output.
4. Close the file and try the **practice question** on your own.
5. Only then look at the answer.
